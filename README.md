# Real-Time Price Calculation Platform

A real-time, event-driven price calculation platform designed for high-traffic workloads.

The project is built with:

- FastAPI
- Apache Kafka
- Spark Structured Streaming
- ClickHouse
- Locust
- Prometheus & Grafana
- Docker Compose

The repository includes the complete architecture, implementation, performance testing, monitoring, and an improved version of the processing pipeline.
